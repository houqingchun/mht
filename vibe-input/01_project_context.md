# 项目上下文与范围

## 1. 产品目标

建设面向中小学校的心理健康筛查与持续关怀平台，形成：

```text
测评任务 → 学生答题 → 自动评分 → 风险提示 → 人工复核 → 跟进 → 家庭回访 → 复测 → 关闭/重新打开
```

系统帮助学校发现需要关注的学生、组织人工工作和查看聚合趋势，不替代心理老师的专业判断，不生成医学诊断。

## 2. V1.0范围

### 必须实现

- 四类角色登录与退出
- 学生按学号登录；心理老师、德育领导按手机号登录；系统管理员使用 `admin`
- 初始密码 `123456`
- 管理员重置所有账号密码
- 学校、年级、班级、学生组织管理
- 学生信息CSV/JSON导入、校验、错误报告、确认导入
- MHT 100题题库导入、校验、草稿版本
- 测评任务创建、编辑、查看完成明细
- 学生移动端/PC端在线答题、自动保存、继续答题、提交确认
- MHT效度、总分、8个维度计算
- 重点学生、待复核、逾期跟进、复测任务工作队列
- 批量分配、批量导出、高度关注学生受控导出
- 学生长期关注档案、跟进记录、家庭回访、复测和关闭/重新打开
- 学校/年级/班级聚合统计与导出
- 敏感查看、导出、复核、跟进、密码重置审计
- 自动化测试、权限测试、边界测试

### V1.0不实现

- AI心理咨询
- AI自动诊断
- 家长端独立账号
- 家校即时通讯
- 在线心理咨询聊天
- 医疗转诊接口
- 多量表商城
- 复杂工作流编排平台

架构应允许未来增加其他量表，但当前只实现MHT。

## 3. 角色概览

| 角色 | 主要目标 | 数据范围 |
|---|---|---|
| 学生 | 完成本人测评、查看完成状态、主动求助 | 本人 |
| 心理老师 | 复核、跟进、家庭回访、复测、查看授权详情 | 授权学生范围 |
| 德育领导 | 查看学校趋势、重点进展和闭环情况 | 学校聚合及必要进展 |
| 系统管理员 | 管理账号、组织、题库、任务和系统参数 | 身份与配置；默认无心理明细 |

## 4. 四层事实模型

1. 原始答题事实：学生每道题的选择。
2. 量表计算事实：效度、总分、维度分数和规则版本。
3. 学校管理事实：重点题命中、待人工复核、跟进状态等。
4. 专业工作事实：心理老师复核、跟进、家庭回访和复测记录。

四层数据必须独立保存。人工复核不能修改原始答卷，关闭档案不能删除历史记录。

## 5. 非功能要求

- 后端鉴权是最终权限来源，前端隐藏不是安全措施。
- 重要读取和所有敏感操作必须可审计。
- 不在日志中打印完整答卷、重点题回答或家庭回访正文。
- 页面支持手机、平板、PC；管理端优先适配宽屏。
- API使用幂等设计，重复提交不得产生重复结果。
- 所有评分规则和题库必须版本化。
