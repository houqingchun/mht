# 业务规则与MHT计算基线

## 1. MHT题目

- 正式题目共100道。
- 每题答案只有“是/否”。
- 原始计分：是=1，否=0。
- 后端是唯一评分来源，前端不得决定最终结果。
- 题目、维度映射、效度题、重点题和解释文本必须配置化。

## 2. 8个内容维度

| 维度 | 题号 |
|---|---|
| 学习焦虑 | 1-15 |
| 对人焦虑 | 16-25 |
| 孤独倾向 | 26-35 |
| 自责倾向 | 36-45 |
| 过敏倾向 | 46-55 |
| 身体症状 | 56-70 |
| 恐怖倾向 | 71-80 |
| 冲动倾向 | 81、83、85、87、89、91、93、95、97、99 |

## 3. 效度量表

效度题为：82、84、86、88、90、92、94、96、98、100。

```text
validity_score = 10道效度题答案得分之和
```

建议状态：

- `VALID`：可信度规则通过
- `QUESTIONABLE`：需要人工判断
- `RETEST_RECOMMENDED`：`validity_score >= 7`，建议择时复测

答卷不得因效度不足而删除。原始答案、效度分数、状态和规则版本必须保留。

## 4. 总分

总分不包括10道效度题，只计算90道内容题。

| 总分 | 筛查分类 | 系统表达 |
|---:|---|---|
| 1-55 | 正常 | 当前筛查结果处于一般范围 |
| 56-64 | 需要关注 | 结果提示可能存在需要进一步了解的倾向 |
| 65及以上 | 重点关注 | 建议由授权心理老师及时人工复核 |

禁止将以上分类改写为精神疾病、临床诊断或确定性风险结论。

## 5. 维度分级

当前V1.0采用：

- `0-3`：LOW
- `4-7`：MEDIUM
- `8及以上`：HIGH

规则必须有 `rule_version`，历史结果不能因新规则发布而自动改变。

## 6. 重点题与学校管理规则

第85题和第97题属于最高敏感重点题。若任一题答案为“是”，系统创建 `MANUAL_REVIEW_REQUIRED` 事件。

界面只能显示：

> 命中重点关注题目，建议心理老师及时人工复核。

不得自动显示：

- 有自杀倾向
- 存在自杀风险
- 患有心理疾病

重点题查看需要二次确认查看原因，并写入审计日志。

## 7. 关注档案

建议关注档案状态：

```text
待复核 → 跟进中 → 观察中 → 已关闭
             ↑             ↓
             └──重新打开───┘
```

关闭档案必须填写原因、说明并确认已检查后续安排。重新打开必须记录操作人和原因。

## 8. 家庭回访

仅记录与学生支持工作直接相关的已确认事实：

- 联系对象
- 回访方式
- 联系结果
- 家庭支持情况
- 沟通事实
- 下次联系日期
- 记录人

不得记录无关家庭隐私，不得将家庭回访正文展示给没有授权的角色。

## 9. 导出规则

- 高度关注导出必须填写用途。
- 默认导出脱敏姓名、学号和必要进展字段。
- 原始答卷、重点题、家庭回访正文默认不在普通导出中。
- 导出范围、字段、操作者、用途和时间必须写入审计日志。
