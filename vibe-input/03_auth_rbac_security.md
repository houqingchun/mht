# 登录、角色权限与数据安全契约

## 1. 登录方式

| 角色 | 登录标识 | 初始密码 |
|---|---|---|
| 学生 | 学号，例如 `S001` | `123456` |
| 心理老师 | 手机号，例如 `13800000001` | `123456` |
| 德育领导 | 手机号，例如 `13800000002` | `123456` |
| 系统管理员 | 固定账号 `admin` | `123456` |

登录接口必须根据账号类型和角色校验，不能仅凭前端传入的角色放行。

## 2. 密码治理

- 数据库只保存密码哈希，不保存明文密码。
- 初始密码为 `123456` 仅用于初始化数据和本地原型。
- 首次登录应标记 `must_change_password=true`，正式系统强制修改。
- 管理员可以重置任意账号为临时密码或随机临时密码。
- 密码重置后要求用户下次登录修改密码。
- 密码至少满足长度、失败次数、锁定时间和历史密码策略；具体值标记 `TODO_BUSINESS_CONFIRMATION`。
- 管理员不能通过密码管理页面查看心理测评明细。

## 3. RBAC权限矩阵

| 能力 | 学生 | 心理老师 | 德育领导 | 系统管理员 |
|---|---|---|---|---|
| 本人答题 | 有 | 无 | 无 | 无 |
| 查看本人完成状态 | 有 | 无 | 无 | 无 |
| 查看学生心理详情 | 无 | 授权范围 | 默认无正文 | 无 |
| 查看原始答卷 | 无 | 单独授权+审计 | 无 | 无 |
| 查看重点题 | 无 | 二次确认+审计 | 无 | 无 |
| 查看学校聚合统计 | 无 | 授权范围 | 学校范围 | 无心理指标 |
| 人工复核 | 无 | 有 | 查看进度 | 无 |
| 跟进/家庭回访/复测 | 无 | 有 | 查看进度 | 无 |
| 导出重点进展 | 无 | 授权摘要 | 管理摘要 | 基础数据 |
| 导入学生 | 无 | 可选授权 | 无 | 有 |
| 导入题库 | 无 | 可选授权 | 无 | 有 |
| 账号重置 | 无 | 无 | 无 | 有 |
| 组织和系统配置 | 无 | 无 | 无 | 有 |

## 4. 数据范围

后端每次查询都必须应用数据范围：

```text
SCHOOL / GRADE / CLASS / STUDENT
```

系统管理员管理组织和账号，但默认不拥有心理数据读取权限。任何跨范围查询必须被拒绝并记录审计。

## 5. 审计事件

至少记录：

- 登录成功、登录失败、退出、账号锁定
- 查看学生详情
- 查看原始答卷和重点题
- 创建/编辑人工复核
- 创建/编辑跟进和家庭回访
- 创建/取消/完成复测
- 导入学生、导入题库
- 导出任何心理相关数据
- 重置密码、修改权限和规则版本

审计字段：`id`、`actor_user_id`、`actor_role`、`action`、`resource_type`、`resource_id`、`purpose`、`ip`、`user_agent`、`result`、`created_at`。

## 6. 安全边界

- 前端路由隐藏不能代替后端鉴权。
- 日志不得打印完整答卷、重点题回答和家庭回访正文。
- 不得将未成年人姓名和原始答卷发送给未经授权的第三方AI服务。
- 下载文件必须使用后端受控导出接口，不允许前端直接拼接敏感数据。
- 生产环境必须使用HTTPS、HttpOnly Cookie或安全Token、CSRF防护和会话过期。
