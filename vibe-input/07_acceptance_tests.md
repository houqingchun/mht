# 验收测试契约

## 1. 认证与账号

- 学生使用 `S001/123456` 登录成功。
- 心理老师使用 `13800000001/123456` 登录成功。
- 德育领导使用 `13800000002/123456` 登录成功。
- 管理员使用 `admin/123456` 登录成功。
- 手机号账号不能以学生角色登录。
- 学生不能访问心理老师工作台接口。
- 未登录访问业务接口返回401。
- 管理员重置账号后，旧密码失效，新临时密码可登录。
- 密码重置写入审计日志。
- 登录失败达到阈值后账号锁定。

## 2. MHT计算

- 100题全部“否”时，内容总分为0，效度分为0。
- 100题全部“是”时，内容总分为90，效度分为10。
- 效度分6、7分别命中正确边界。
- 总分55为正常，56为需要关注，64为需要关注，65为重点关注。
- 维度分3为LOW，4为MEDIUM，7为MEDIUM，8为HIGH。
- 第85题“是”创建人工复核事件。
- 第97题“是”创建人工复核事件。
- 第85和97都为“否”时不因重点题创建事件。
- 答案不足100题禁止提交。
- 非YES/NO答案禁止保存或提交。
- 重复提交保持幂等，不重复生成结果和风险事件。
- 历史结果保留计算时的量表版本和规则版本。

## 3. 关怀闭环

- 待复核学生可以创建人工复核。
- 人工复核必须填写结果和已确认事实。
- 跟进记录必须填写事实和下次日期。
- 家庭回访只展示给授权心理老师。
- 德育领导只能看到必要进展和聚合数据。
- 关闭档案必须填写原因、说明和确认勾选。
- 关闭后历史记录仍可查询。
- 已关闭档案可以重新打开并记录原因。
- 安排复测后出现在复测任务列表。
- 学生趋势仅展示分数事实变化，不生成“已经治愈”等判断。

## 4. 导入导出

- 学生导入支持CSV和JSON。
- 缺少学号、姓名、年级、班级的记录进入错误报告。
- 重复学号不得写入。
- 题库导入必须校验100题、题号完整、10道效度题、重点题数量和维度映射。
- 导入必须先预览再确认写入。
- 高度关注导出未填写用途时禁止导出。
- 普通导出默认脱敏，不包含原始答案和家庭回访正文。
- 导出行为写入审计日志。

## 5. 权限与审计

- 系统管理员不能默认查看学生心理详情。
- 德育领导查看学生档案时不返回重点题和访谈正文。
- 未授权用户不能调用重点题接口。
- 查看重点题必须填写查看原因。
- 查看学生详情、查看重点题、导出、复核、跟进、家庭回访和密码重置都必须写审计。
- 审计日志不得包含完整答案和敏感正文。

## 6. UI/UX

- 登录页可按角色切换账号类型，并动态改变账号字段提示。
- 所有关键操作有成功/失败反馈。
- 所有删除、关闭、提交、导出和敏感查看有二次确认。
- 学生答题支持自动保存、继续、定位未答和提交锁定。
- 360px宽度下学生答题页面可使用；管理表格可横向滚动。
- JavaScript不可用时页面不应白屏，应显示静态首屏和下载提示。

## 7. 自动化测试最低要求

- 单元测试：Scale Engine、密码策略、权限策略、CSV解析、导出脱敏。
- API测试：认证、测评提交、导入、关怀、导出、审计。
- 集成测试：从任务创建到提交、风险事件、复核、跟进、复测和关闭。
- E2E测试：四类角色登录并完成各自可用路径。
- 安全测试：越权访问、IDOR、重复提交、敏感日志泄露。
