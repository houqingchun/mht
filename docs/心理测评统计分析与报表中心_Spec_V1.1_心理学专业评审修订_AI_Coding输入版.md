## 1. 产品目标、分析边界与术语

### 1.1 业务目标

- 学校层：知道本次有效测评样本覆盖情况、筛查信号分布及八维度统计表现，辅助确定校级心理健康教育关注主题。
- 年级层：在**同一任务、同一量表/规则、同一统计时点**下观察不同年级维度分布差异。
- 班级层：查看本班统计及与同年级的描述性对比，辅助心理老师考虑差异化班级心理教育；不能自动推断班级好坏。
- 个体层：在独立授权下复用已有学生测评结果/关怀档案，**不在领导聚合报表中直接暴露个人明细**。

### 1.2 统计概念（严禁混用）

| 术语 | 定义/约束 |
|---|---|
| 任务目标人数 T | 该任务目标学生快照及已批准补发形成的去重目标人数，不等同于当前全校名册人数 |
| 已确认非应测人数 E | 已按 V1.2 对当前任务生效的请假/免测/已排除去重人数；是否生效由后端确定 |
| 实际应测人数 D | `D=T−E`，用于**任务完成率**分母；D=0 时完成率为“—” |
| 有效完成人数 C | 属于本任务实际应测范围、已经产生当前有效结果的学生去重人数 |
| 任务完成率 | `C/D×100%`，**不是**筛查信号检出比例 |
| 统计有效样本 N | 在所选任务/组织范围中按结果有效性与筛查口径可纳入**指定指标**的人数；不同指标 N 可不同 |
| 任一筛查信号人数 S | 统计有效样本中触发至少一种指定筛查信号的**去重学生数**，不同信号分项允许交叉 |
| 维度平均分 | 此维度参与统计的有效分数和 / 此维度有效可评价人数 `N_dim`；展示分值范围与方向 |
| 维度得分分布 | 依据正式量表分段规则计算低、中、高（或配置的合法区间）人数/比例；分段应互斥且覆盖该维度有效结果 |
| 维度高分人数 H_dim | 符合正式维度高分条件的去重学生数；这是**维度分值区间指标**，不自动等于普通筛查/重点题信号人数 |
| 维度高分比例 | `H_dim/N_dim×100%`，分母为当前维度可评价人数，不是任务应测人数 |
| 指定维度筛查人数 R_dim | 若正式规则存在可归属到该维度的筛查条件，则按该规则求去重学生数；否则显示“该量表未配置此指标” |
| 指定维度筛查比例 | `R_dim/该筛查规则要求的有效可评价人数`；与高分比例分别标识，分母来自后端定义 |
| 统计快照 asOf | 同一页面所有数字和图表必须来自同一后端快照/版本，避免前后矛盾 |

> 量表筛查是心理健康教育的辅助线索，不能等同医学诊断、疾病患病率或自动紧急处置。首页不出现“心理问题班级排名”“最差学生”等标签。

### 1.3 统一计算约束

1. 相同任务与统计模式下，同一学生只使用**一份当前有效结果**；在线与外部历史、复测事实保留，不能累加成多个人。
2. 学生多种信号可以同时出现；展示各信号类型人数时标记“不可求和”。总体任意信号人数按 `studentId` 去重。
3. 维度得分有效性可能与总分有效性不同；分别返回样本分母与排除数，不以任务完成率分母代替。
4. 不同维度原始满分不同，平均原始分不可据大小直接推导相对关注程度。跨维度可优先展示各维度各自的高分比例/分布，或由正式量表提供的可比转换值。
5. 未确认身份、评分失败、外部结果冲突未处理、效度不满足所选指标要求、任务外未确认的事实不纳入正式主分析；理由以真实后端状态码返回。
6. 所有百分比四舍五入展示一位小数；计算基于未四舍五入原值。`N=0` 展示“—”而非0%或100%。未知/加载中≠0。
7. 多任务合并仅在量表及统计口径兼容、明确去重与日期归属时允许；首期默认**单任务分析**，学校跨期趋势独立提供统计模式选择。

### 1.4 样本质量与效度分层（V1.1 新增，必须贯穿所有报表）

| 指标/集合 | 统计解释 | 强制显示/处理 |
|---|---|---|
| 任务目标人数 `targetCount` | 任务目标快照内去重人数 | 用于任务范围说明，不能代替心理维度有效样本 |
| 实际应测人数 `eligibleCount` | 依据 V1.2 已生效的非应测处理形成 | 用于任务完成率与覆盖率分母，非应测原因另列 |
| 技术已完成 `completedCount` | 已形成符合任务有效结果规则的去重人数 | 不等同于“心理测量解释完全可信”；保留评分状态 |
| 效度未触发复测建议 `validityUnflaggedCount` | 已计算且未触发正式效度提示的结果人数 | **不是**临床意义的绝对有效保证 |
| 效度提示/建议复测 `validityFlaggedCount` | 依正式效度配置触发建议复测的人数 | 单独展示；不自行宣告结果无效或删除历史答卷 |
| 指标可评价 `nEvaluable` | 在当前指标、当前分析模式下满足纳入规则的人数 | **每个维度独立返回**；缺答/版本不兼容等可致不同 N |
| 样本覆盖率 `coverageRate` | 当前指标可评价人数 / 实际应测人数 | 展示分子分母；对低覆盖率只做审慎提示，不臆造合格阈值 |
| 不纳入原因 `excludedByReason` | 身份未确认、无可比评分、版本不兼容、来源核验未通过、当前分析模式排除等 | 按实际状态码统计；**不得将“效度触发复测”天然认定为技术无效** |

**分析模式设计：**`analysisMode=ALL_CALCULATED` 为“全部已计算且满足该指标基础条件的结果”；`analysisMode=VALIDITY_UNFLAGGED` 为“效度未触发提示且满足指标条件的结果”。是否开放两种模式及默认主分析口径，须由学校心理专业负责人根据正式 MHT 使用规范与 V1.2 结果纳入规则签署确认；未确认前，原型允许模拟切换但真实报表不自动选择主口径。模式切换后，所有 KPI、各维度 N、图表、年级/班级基准、导出、摘要必须同步重算。`ALL_CALCULATED` 不等于所有上传记录，仍须满足唯一当前结果、身份/任务归属、计算/来源校验条件。

**解读提示：**页面必须明确写出“本报表呈现的是已纳入样本的筛查得分分布，并不代表未参与学生的状况”；覆盖率不充分、存在大量效度提示、施测条件不一致或某个单元格样本量较小时，显示相关事实和“谨慎解释”，禁止由前端预设任意覆盖率阈值。群体未完成与效度存疑数字不得直接叠加成“无效人数”，避免重复。

### 1.5 心理测量与专业表述边界（V1.1 新增）

1. 所有维度正式 code、名称、分数范围、计分方向、分段阈值由已确认 MHT 量表配置获取。示例中不硬编码维度满分、8分高分线或效度7分线；正式评分依据与配置若不符必须提示并停止相关指标上线。
2. 学习焦虑、对人焦虑、孤独倾向、自责倾向、过敏倾向、身体症状、恐怖倾向、冲动倾向，仅在正式配置与项目基线一致时使用这些中文名称。“过敏倾向”是心理测量术语，**不是身体过敏疾病**。
3. 原始均分用于描述维度内部得分，跨不同满分/题数维度不得据均分大小声称“更严重”。如已正式配置并验证适用的标准分/常模，另起已版本化字段展示；不得自行将原始分除以满分后称为心理风险指数。
4. “维度高分人数/比例”指正式得分分段；“该维度筛查信号人数/比例”仅在正式规则具有该维度归属时提供；两者命名、分母和含义不能互换。不同维度高分比例可描述分布，不等于跨维度临床严重性比较。
5. 统一用“量表筛查信号”“某维度高分结果”“建议人工核查”“建议复测”等中性文案；禁止“确诊”“患病率”“最差班级”“干预有效”“问题最严重维度”等从统计值直接导出的结论。
6. 页面“统计事实”区允许严格模板化表达实际 N、比例、时间、基准；“专业研判”是心理老师独立确认的记录，不得由 AI 文案冒充人工意见；系统不得用班级统计自动下发个体处置指令。

## 3. 全局筛选器、页头及状态

### 3.1 公共页头 `AnalyticsPageHeader`

左：面包屑、中文报表标题、一句用途说明；右：刷新、授权导出（如适用）、数据截至时间及规则版本入口。不要将导出敏感明细作为首页主按钮。

### 3.2 公共筛选 `AnalyticsFilterBar`

| 字段 | 默认/约束 | 行为 |
|---|---|---|
| 学校 | 后端当前授权学校固定 | 不提供任意跨学校输入和越权切换 |
| 测评任务 `taskId` | 用户授权、可用于统计的最近任务或显式选择 | 必选；不存在任务时显示空态；切换后重置失效的年级/班级 |
| 测评时间 | 任务实际测评时间范围；趋势页单独支持多期 | 与导入时间区分；按学校时区展示 |
| 年级 `gradeId` | 全部授权年级 | 全校页允许筛选，进入年级页后作为固定上下文 |
| 班级 `classId` | 按年级和授权范围联动 | 选择班级进入班级画像；年级变化清除失效班级 |
| 维度 `dimensionCode` | 全部八维度/单一维度（按页） | 维度详情/下钻保留选择 |
| 指标 `metric` | 默认“维度高分比例”；可切换平均分/分布/高分人数/正式筛查人数比例 | 图表、明细表、图例、说明与分母同步变化 |
| 统计模式（趋势） | 当期群体 / 同一学生纵向 | P1；切换模式不沿用不兼容数据 |

筛选采用“选择后显式查询”或统一自动查询策略，**同一模块保持一致**。请求未完成时保留当前已确认结果并显示更新中，不混合新旧筛选条件数据。重置仅重置有权修改的字段。

### 3.3 全部图表的通用信息栏

固定展示：`统计人数 N`、`统计任务/区间`、`量表及评分规则版本`、`数据截至 asOf`、`分母说明`、`有效性排除提示`。图表下始终提供可访问的数据表视图，导出的统计数字不得突破当前筛选/授权/小样本限制。

### 3.4 页面状态矩阵

| 状态 | UI 反馈 | 禁止事项 |
|---|---|---|
| 初次加载 | 与真实结构同形骨架，显示“正在加载统计” | 先出现假0 |
| 筛选无数据 | “该条件下暂无可评价结果”及清除筛选 | 以“0%”代替无数据 |
| N=0 | 人数0、比率和均值“—” | 分母0强行计算 |
| N<5 | “样本过小”，仅在明确允许范围内显示计数；均值、比例、分布图隐藏或合并 | 用颜色、tooltip、导出、接口或父级差值泄漏被抑制结果 |
| 请求失败/超时 | 就地错误信息、重试、保留合法筛选 | 把缓存冒充最新快照 |
| 无权限 | 不暴露资源是否存在；展示无权访问或资源不可用 | 仅在前端隐藏姓名却返回明细 |
| 部分数据不可评价 | 显示有效人数、排除人数与原因 | 将排除学生计为低分 |
| 跨期规则不可比 | 禁止连成一条趋势线，显示差异说明 | 自动转换未经确认的不同量表版本 |

### 3.5 全局新增交互：样本与解读模式

`AnalyticsFilterBar` 必须展示当前分析模式、当前任务及规则版本；`SampleQualityStrip` 固定显示应测/技术完成/各指标可评价人数/效度提示人数/覆盖率，并提供“纳入与排除说明”。模式为心理测量**纳入样本选择**而非操作数据有效状态，不写回测评结果。样本口径尚未确认或某指标数据缺失时，该指标显示“口径待确认/暂无可评价数据”，不可把未知样本按0处理。全局切换分析模式应重置不兼容缓存，保留任务、年级、班级与已选维度，并刷新同一快照关联图表和表格。

## 4. RPT-01 全校心理筛查预警总览（P0）

### 4.1 用户要回答的问题

- 本次任务有效测评覆盖情况如何？
- 出现至少一种筛查信号的去重学生规模、比例是多少？
- 普通筛查、重点题人工复核、效度复测建议分别涉及多少学生，有多少待处理？
- 这些信号在年级/班级的**聚合分布**如何？

### 4.2 页面结构（自上而下）

1. 公共页头 + 任务/时间筛选 + 口径说明。
2. KPI 4卡：有效测评人数 N、任一筛查信号去重人数 S、筛查信号检出比例 S/N、待人工复核工作项数（标注“项”而非“人”）；另给“任务完成率”次要链接，不混为信号检出率。
3. `SignalTypeBarChart`：三类信号分别按涉及学生数展示；图例说明“同一学生可能重复出现在不同类别，不可求和”。
4. `GradeSignalSummary`：年级有效人数、信号人数、比例及待处理工作项的矩阵/条形图；在有权限且样本达标的前提下允许下钻班级。
5. `WorkSummary`：已复核/待复核、已建档/跟进中等**工作过程指标**，与“筛查人数”单独区域显示，切勿渲染成所有人都应转入下一阶段的强制漏斗。
6. 图表对应数据表、统计口径、时间戳与后端归因代码。

### 4.3 指标/数据契约

| 字段 | 类型 | 显示 | 约束 |
|---|---|---|---|
| `sampleCount` | int | 有效测评人数（人） | 明确有效性口径 |
| `signalStudentCount` | int | 存在信号的学生（人） | 跨信号去重 |
| `signalRate` | decimal/null | 信号检出比例（%） | `signalStudentCount/sampleCount`；分母0/小样本返回null及状态 |
| `signalTypeStats[]` | array | 类别/人数/工作项 | 普通筛查、重点题、效度复测；人数不求和 |
| `gradeStats[]` | array | 年级分布 | 附样本N、suppression标识 |
| `asOf`、`ruleVersion` | ISO/string | 截至时间、口径版本 | 全页面同快照 |
| `analysisMode`、`sampleQuality` | enum/object | 本次纳入模式、应测/技术完成/可评价/效度提示/覆盖率 | 切换模式必须联动全页；不把效度提示自动等同无效 |

### 4.4 交互 ACT-RPT01

- 点击类型条形→带入 `signalType` 进入年级分布或筛查工作概览，不自动显示个人敏感答案。
- 点击年级→带入 `taskId+gradeId+signalType` 进入年级分析；点击班级→班级画像。
- 心理老师如有独立学生名单权限，可从对应统计指标进入授权工作项列表；德育领导默认止于聚合统计和必要进展。
- 状态小样本、无权或计算失败时，柱条/卡片不支持试探性点击获取被抑制值。

### 4.5 V1.1 专业增强：区分信号与工作处置

1. 筛查信号、量表效度提示、重点题人工复核、已人工确认的关怀结果分开展示；**原始信号不是已经确认的心理问题，更不是疾病诊断**。同一学生多类信号可以交叉，卡片同时标示“去重人数”和“工作项数”而不将其混为一谈。
2. 新增工作摘要：`pendingReviewWorkItems`、`completedReviewWorkItems`、`overdueReviewWorkItems`、`activeCareStudentCount`；工作项数不得直接代替人数；报表的时间范围/责任范围与工作队列统计范围分别标记。
3. 点击“待人工复核”只能进入既有**授权工作队列**；普通聚合视图不展示具体敏感题目答案。后续查看重点题具体答案遵循专门权限、查看原因及响应前审计，不因点击图表绕过。
4. 效度提示有独立人数和当前处理进度；**不自动**与评分失败、身份未匹配等技术异常合并。

## 5. RPT-02 全校八维度分析（P0）

### 5.1 用户要回答的问题

- 八个维度各自的平均分、得分分布、高分人数和比例分别是多少？
- 哪些维度出现较多**按正式规则定义的筛查信号**？
- 本次有效样本覆盖是否足够，是否因效度、缺失或来源规则而被排除？

### 5.2 页面组件

1. `DimensionMetricSwitcher`：高分比例（默认）、平均分、得分分布、高分人数、正式筛查人数及比例（若有定义）；高分区间与正式筛查信号绝不混名。
2. `DimensionHorizontalBarChart`：纵轴维度正式名称，横轴所选指标；人数/分数/%切换时单位和轴刻度同步更换。默认按正式维度顺序；允许按当前数值排序但**仅对指标排序**，不出现学生/班级评价排名。
3. `DimensionDistributionChart`：每个维度低/中/高互斥区间的100%堆叠条形图，旁边给出人数、N及“评分区间配置”。若实际规则不是三档则从配置动态生成。
4. `DimensionTable`：维度、满分/方向、N、平均分、中位数（如后端支持）、低中高各人数与比例、高分人数/比例、正式筛查人数/比例（若有配置）、排除数。
5. `DimensionInsight`：点击维度显示其年级分布、统计依据，不自动生成“该维度导致心理疾病”等结论。

### 5.3 指标契约

| 字段 | 说明 |
|---|---|
| `dimensionCode` / `dimensionName` | 后端正式配置和展示顺序 |
| `scoreMin` / `scoreMax` / `scoreDirection` | 明确原始分范围与方向，均值展示须标注满分 |
| `nEvaluable` / `nExcluded` | 本维度有效可评价人数及不纳入人数 |
| `meanScore` / `medianScore` | 聚合统计值；原始值不可在跨不同满分维度间直接比较 |
| `distribution[]` | `rangeCode,label,count,rate`，区间互斥、计数合计=N |
| `highScoreCount` / `highScoreRate` | 维度高分区间人数及比例 |
| `screeningCount` / `screeningRate` / `screeningRuleAvailable` | 仅在正式规则明确时展示对应维度筛查指标；否则显示“未配置” |
| `suppressed` / `suppressionReason` | 隐私抑制和辅助抑制状态，前端不可自行从其他字段复算 |
| `analysisMode` / `validityFlaggedCount` / `coverageRate` | 纳入模式、效度提示及可评价覆盖情况；与全页样本质量区一致 |

### 5.4 交互 ACT-RPT02

- 切换指标→同维度组、同任务、同快照同步更新图表与表格；切换“平均分”显示 `x / 满分`、分数方向提示。
- 点击某维度→保留指标与时间上下文，显示该维度在年级的聚合分布。
- 可选“查看统计口径”展开公式、N、排除理由、规则版本；不默认泄漏学生名单。
- 需明确“维度高分率”是量表分值指标，不可将其柱状图标题写成“疾病率/心理问题发生率”。

### 5.5 V1.1 专业增强：解读、效度与共同高分

- 八维度图表上方显示 `SampleQualityStrip` 与分析模式；每个维度返回 `nEvaluable`、对应分母、效度提示/缺答等排除说明。分析模式变更后均分、分布、高分/筛查人数及比例必须联动，禁止仅修改表头。
- 均分视图标注“原始分 x / 该维度满分”“跨不同满分维度不作严重程度比较”；高分比例视图标注“达到正式得分区间的比例，不是患病率或统一风险评分”。
- 新增 `CoHighScoreSummary`（P1，可先做占位，不影响 P0）：同一学生**恰好一个维度高分**、**两个及以上维度高分**、常见高分组合人数。计数按正式维度条件及当前纳入模式去重；不得解释为复合疾病或更高危险度。组合统计应用相同的小样本、差分保护与权限过滤，德育领导默认不可查看组合后的个人明细。
- 每维度提供正式量表说明入口，显示配置版本、题目数/满分/分数方向/区间规则/筛查解释边界；**仅呈现正式批准文本**，不能让大模型根据维度名称编造医学含义。

## 6. RPT-03 年级心理维度对比（P0）

### 6.1 页面结构

1. 页头任务与时间、年级多选（默认全部授权年级）、指标切换。
2. `GradeDimensionHeatmap`：行=年级、列=八个正式维度，单元格=所选指标+明确单位；颜色深浅只辅助表示数值，**不代表临床风险等级**。
3. `SelectedGradeSummary`：点击年级展示人数 N、八维度平均分/分布/高分人数比例四类指标及该年级筛查信号汇总。
4. `GradeToClassMatrix`：该年级各班级×维度矩阵，附样本量及小样本标记。
5. 详情表与口径说明；年级之间样本量不同，优先比较明确分母的比例而不是绝对人数。

### 6.2 矩阵交互

| 操作 | 结果 |
|---|---|
| 切换指标 | 单元格数值、单位、色阶、图例、tooltip、表格同步切换 |
| 点击年级行 | 保留年级筛选，展开年级详情与班级列表 |
| 点击单元格 | 带入年级+维度进入对应班级分布，不直接打开某学生 |
| 点击班级 | 进入 RPT-04，保留任务、时间、维度和来源页面 |
| 点击被抑制单元格 | 不可查看详情，不在 tooltip/导出/其他图表泄露值 |

### 6.3 统计要求

聚合结果必须使用同一任务/量表规则版本及结果有效性定义；页面按年级显示每个维度的 `N`。若班级/年级人数不足，单元格按后端隐私规则抑制；在上级合计中还需执行必要的补集抑制，避免反向求出小组人数。

### 6.4 V1.1 专业增强：年级样本质量与比较条件

- 增加 `GradeSampleQualityPanel`：逐年级显示任务目标、实际应测、技术完成、各维度可评价人数、效度提示人数、未完成与可评价覆盖率（分子分母均需显示）；不同年级 N 不一致时，不只显示比例。
- 年级热力矩阵只提供**同一分析模式、同一时间/任务、同一量表版本与评分口径**下的描述性比较；颜色强弱仅反映该列数值大小，不用于标记“差班/好班”或给年级评估分数。
- 某年级覆盖不足、样本量小、施测时点与其他年级不同或效度提示比例偏高时，展示实际数值与“谨慎解释”提示；没有正式批准的门槛时，不能凭固定算法标注“可信/不可信”或统计显著性。
- 可提供正式计划内的同年级班级差异入口；不同学生构成、施测环境、考试周期等可能影响结果，**不得由系统自行断言差异原因**。

## 7. RPT-04 班级心理维度画像（P0）

### 7.1 页面结构

1. 班级名（授权范围）、任务、量表版本、数据截至。
2. 3～4张统计卡：任务目标数、实际应测数、有效测评人数、有效样本覆盖率；**覆盖率分母明确**，不要标成维度检出率。
3. `ClassVsGradeDimensionChart`：八维度本班 vs 同年级的**同类型指标**分组条形图；支持平均分（附满分）、高分人数/比例、分布与正式筛查人数/比例切换。
4. `ClassDimensionTable`：每维度本班 N、均分、区间分布、高分人数及比例；同年级相同指标、绝对差（百分点或分）、统计说明。
5. `ClassFactSummary`：仅基于本次后端统计事实生成模板化描述，如“该班该维度高分比例为 X%，同年级为 Y%，有效样本分别为 N/M”；不出现“心理最差班级”“X问题严重”等归因。
6. `NextActionArea`：心理老师根据职责可以进入授权学生测评/工作项；德育领导只看已允许的聚合概况。个性化教育主题建议可作**人工确认的参考**，不是自动诊断或强制干预。

### 7.2 比较口径

- 同年级比较对象：同任务、同量表规则、同时间与有效结果口径；明确同年级统计是否**包含当前班级**，首期建议包含，并在图例注明。
- 本班与年级均需展示 `N`；数值差较大也不应直接解释为统计显著，更不能给班级打分/排名。
- 对于不同满分维度，禁止把原始均分当作统一程度指数；如有正式标准化算法必须明确版本，未配置时不显示“统一心理指数”。
- 小样本被抑制时不得展示百分比、均值、精确差值、tooltip、明细导出；应同步处理年级总数和其他班级导致的补集泄露。

### 7.3 交互 ACT-RPT04

- 选择班级→校验所属学校/年级权限及任务范围→全页刷新同快照。
- 选择单一维度→聚焦该维度图/表与已配置的筛查规则解释。
- 心理老师点击“查看授权学生工作事项”→跳转已有业务页面，并二次鉴权；不把个人分数表嵌入领导版班级报表。
- 若班级缺乏可评价学生→展示空态/样本不足与覆盖情况，禁止生成总结性断言。

### 7.4 V1.1 班级画像专业研判区（P0 UI，正式持久化待确认）

**明确分层，不把统计事实直接转化为干预命令：**

1. `ClassSampleQualityPanel`：班级目标/实际应测/技术完成/维度可评价 N/效度提示/未完成/覆盖率；若有效人数显著少于应测人数，只陈述“目前结果仅覆盖已纳入样本”，不推断全班。
2. `ClassFactSummary`：仅使用真实快照中的指标生成中性统计文案；每句同时展示本班和年级的 N、当前分析模式与比较时间；示例“本班该维度高分 X/N，与同年级 Y/M”，不生成“学生更容易患某种疾病”。
3. `ProfessionalInterpretationPanel`：统计事实（只读）与“心理老师专业研判”（独立、可编辑）分区。老师可记录施测背景、覆盖率/效度限制、学生反馈/实际观察的适当摘要、需要进一步核查的问题、所选教育主题及后续观察方法。**首期原型仅交互演示/复用既有获授权记录入口**；新增保存、审核、电子签名或数据库字段须业务确认后单独开发。
4. `EducationTopicReference`：只能给出与正式量表维度相对应的**主题候选**（如学习适应、同伴沟通等须专业审核的词库），由心理老师确认；不自动给全班或学生下达强制性干预。班级教育面向整体学生，不公开高分学生名单或将个人信息写入活动展示。
5. 小样本下禁止拼接能反推出被隐藏值的班级/年级差值摘要；不能因“专业研判”自由文本或复制导出绕过隐私策略。不得将班级统计直接用于教师/班级绩效排名。

**德育领导默认不提供学生明细下钻。** 不能通过修改 URL、前端查询参数、统计导出、搜索建议或接口直接获取学生身份/答卷/家庭回访正文。

### 8.1 V1.1 个体解释与多来源信息

学生详情必须标注效度状态、当前有效结果与历史结果、每维度原始分/满分/正式区间；区分单次量表结果与心理老师后续人工核查。可以从**已获授权**的现有学生关怀时间线查看访谈、跟进、复测、家庭回访等适当信息，但不得让量表自动得出疾病诊断、预测危险行为或建议直接关闭档案。没有新增权限即不显示个人信息；原始重点题答案与家庭回访正文继续按专门权限、原因与审计处理。

## 9. RPT-06 心理维度历史趋势（P1，须单独确认排期）

| 模式 | 样本口径 | 图表与要求 |
|---|---|---|
| 当期群体趋势 | 每期各自有效评价的群体；可能不是同一批学生 | 各期均分、高分人数/比例、样本量和覆盖率；不可直接描述成“同一批学生改善” |
| 同一学生纵向趋势 | 仅保留选定时间点均有可比有效结果的同一学生集合 | 同群体的指标变化、每期学生数一致性、样本流失说明 |

- 若所选时期量表版本、得分方向、阈值不兼容，应分段展示或中止直接对比并解释原因；不得自行生成转换公式。
- 群体统计不能证明某教育活动的因果效果。允许展示真实测评时间点与当期已记录的教育活动，但不自动生成因果结论。
- 个体趋势复用学生结果详情权限，不在领导趋势报表展示可识别个人轨迹。

### 9.1 V1.1 历史变化的专业解释

- **描述分值变化，不宣告心理状况改善/恶化：**展示实际分、差值、正式区间变化、测评日期与 N；例如“9分→7分，分段由高分区间变为中分区间”，不能直接写“干预有效”。
- 若希望提示可靠变化，须有适用人群的正式信度/测量误差等方法学依据以及已批准算法和版本；未具备时禁止自行设定“变化≥2分即改善”等阈值。
- 群体前后期结构可能不同；需显示参与/缺测与样本流失情况。“当期不同群体”与“同一学生追踪”明确切换，学生升年级后仍依据稳定 ID 关联，但历史班级归属遵循当期快照。
- 教育活动前后变化只是观察性关联，不能由平台自动认定活动造成了变化。

## 10. RPT-07 心理健康教育与关怀措施跟踪（P1，业务扩展待确认）

> V1.2 的个人关怀记录已经具备业务边界；**新的班级/年级公共教育活动实体不因本报告自动成为已确认建设内容。** 当期可先做“教育主题参考展示”和跳转已有记录；若建设活动管理，需先确认对象与DDL/API。

建议数据项：活动ID、适用范围（学校/年级/班级）、选用的统计快照ID/维度、活动名称/主题、负责人、计划与实际时间、开展状态、匿名参与统计、后续观察文本和可访问权限。允许查看活动前后统计差异，但不自动断言活动带来了改变，也不把个体心理测评结果公开到活动名单。

### 10.1 V1.1 新增可选能力：匿名教育需求（P1，待独立确认）

在已获学校同意、明确告知目的和数据使用边界时，可收集匿名、非诊断性的教育主题需求（例如考试应对、同伴沟通、情绪调节）。该结果与 MHT 原始答卷、八维度评分及学生筛查信号**分别存放、分别展示，不回写量表评分**。不因学生未达到高分区间就排除其获得普及性心理健康教育的机会。匿名样本极小时同样受披露限制。首期不默认新增问卷系统或班级活动数据表。

### 10.2 V1.1 新增教育活动效果表达约束

教育活动跟踪仅展示实施事实、参与范围的非识别性统计、学生反馈及后续分数分布观察；无对照和正式评价方法时不得声明活动“导致改善”或据此给班级、教师打分。班级活动范围与学生个人关怀事实分别授权管理，不将个人测评名单直接暴露给活动参与者。

## 11. 权限矩阵与统计隐私

| 能力 | 心理老师 `COUNSELOR` | 德育领导 `LEADER` |
|---|---|---|
| 全校/年级/班级聚合统计 | 仅本人授权数据范围 | 本校授权聚合及必要进展摘要 |
| 八维度均分/分布/人数/比例 | 授权且通过小样本规则后 | 授权聚合且通过小样本规则后 |
| 班级统计下钻 | 授权班级，按规则可进入工作项入口 | 仅授权聚合；不默认提供学生身份 |
| 个人测评得分/原始答卷 | 具体授权范围；原答卷另行授权 | 默认无权 |
| 重点题具体答案 | 额外字段授权、查看理由、响应前审计 | 不开放 |
| 家庭回访正文 | 按独立个体权限 | 不开放 |
| 报表导出 | 统计导出受控；如涉及个人明细须用 `export_job` 等既有审计流程 | 仅获准的聚合报告/进展摘要，仍适用小样本限制 |

**抑制规则：**分母<5的群体不输出均值、比例、指标排序或分布图；可见计数必须在正式隐私策略允许的范围内展示。按类别叠加、上下级相减、切换一个班级/时间窗口、对照 CSV 导出等均可能识别某学生，须实施后端补集抑制或合并分组，而不是前端隐藏图形。API 权限先于缓存读取；权限变更清理前端敏感缓存。管理员不因管理账号而天然具有心理明细访问权。

### 11.1 V1.1 组合筛选与差分防护实现要求

- 延续需求 V1.2 已确认的小样本规则：分母小于5不输出比例、均值、指标排序；对允许显示的计数仍需检查是否能够关联到个人。**分母达到5并不等于一定安全。**
- 后端对同任务的学校/年级/班级、时间区间、维度组合、分析模式切换和下载内容实施一致的发布策略；必要时合并组别、同步抑制补集/关联单元格或拒绝过细查询，防止“全校−某年级”“全班−已完成者”等反向推算个人数据。
- 抑制标识必须随 API 输出，前端不接受被抑制原始值、更不能在 tooltip、表格、缓存或导出返回。后端需对可识别性和高维组合查询做实际测试，而不只是固定单元格阈值。
- 不对德育领导开放组合高分结果的名单查询；心理老师的个体详情要通过已有业务级授权重新校验。日志避免记录明文个人得分、重点题答案或敏感自由文本。

## 12. UI Design System 对齐与页面组件清单

### 12.1 布局与风格

- 复用现有深蓝侧栏 `#0B3553`、白色内容卡片 `#FFFFFF`、浅灰蓝画布 `#F5F8FC`、主按钮 `#0876D9`；采用 Design System 中的颜色/字号/圆角/间距 Token，禁止页面私设另一套图表主题。
- 基准 1920×1080；检查 1440×900、1366×768；侧栏展开248px、顶栏72px；主内容水平内边距24px（窄屏遵循 Design System）。
- 大屏优先：页头→筛选栏→4张KPI→主图表与解释→可访问数据表。不要在同一屏堆放七张报表；每张报表是可独立进入的页面。
- 表格文本左对齐、数值右对齐且等宽数字；图例必须写单位、分母和分值方向；颜色**不得是唯一信息编码**。
- 交互组件包括：`AnalyticsPageHeader`、`AnalyticsFilterBar`、`KpiCard`、`DimensionMetricSwitcher`、`DimensionHorizontalBarChart`、`DimensionDistributionChart`、`GradeDimensionHeatmap`、`ClassVsGradeDimensionChart`、`AnalyticsDataTable`、`PrivacySuppressedCell`、`StatMethodPopover`、`ReportExportAction`；优先复用现有基础组件库与路由。

### 12.2 图表选型和反例

| 信息 | 使用 | 禁止/注意 |
|---|---|---|
| 八维度高分人数与比例 | 横向条形图、附N的统计表 | 不命名为“疾病率” |
| 八维度均分 | 横向条形图，逐维度显示满分/方向 | 不直接按原始均分跨不同分值范围定性排名 |
| 维度得分分布 | 100%堆叠条形图 + 人数表 | 区间不可重叠，不能仅靠颜色表达 |
| 年级/班级对比 | 热力矩阵/分组条形图 | 热力颜色是数值编码，不是临床风险定级 |
| 不同时期变化 | 带样本量与规则版本的折线图 | 不兼容版本不能连成连续趋势 |
| 个体维度结果 | 原始分/满分条形图 + 正式解释 | 无正式统一转换时不画误导性的统一尺度雷达图 |

### 12.3 交互状态

所有控件应有默认、悬停、键盘焦点、禁用、加载、错误、成功或状态未知反馈。图表切换时焦点可用、读屏可得到等价数据表；对精细矩阵提供键盘导航和单元格语义；Tooltip 不独占关键信息。空态、无权、无数据、样本过小、后端超时/部分失败使用不同文案。

## 14. Mock 数据规范（可用于 AI Coding 原型）

首期开发至少准备一套互相关联的模拟数据：1个学校、1个当前测评任务、3个年级、每年级若干班级、任务目标快照、有效结果与无效结果、三类筛查信号、两名以上同一学生触发不同信号、在线与外部结果冲突和未解决情况、历史测评任务及权限样例。**学生姓名/学号为虚构值，演示页面必须显示 Mock/演示水印，不可混合真实数据。**

数据校验：

1. 学校维度统计由班级/年级相同有效结果口径聚合；如果存在转班或跨时段归属，使用指定归属快照规则，不得简单求和。
2. `任一信号去重人数 ≤ 有效样本人数`；三类信号人数之和允许大于去重人数。
3. 同一维度 `low+medium+high = nEvaluable`（在正式量表确为该三档时）。
4. `highRate = highCount/nEvaluable`；各层级数值计算不依赖 UI 中只加载的前 10 条名单。
5. 未确认/冲突的外部结果不增加统计人数；同一学生同任务两份来源只选一份当前有效结果。
6. 德育领导 Mock 登录时学生详情 API 模拟返回无权，不能只是导航按钮隐藏。
7. 各层级小样本抑制与导出一致，且不能通过两张表相减恢复被隐藏人数。
8. 维护同一任务的效度提示/未提示、不同纳入模式、技术完成和可评价样本，模式切换时所有层级 KPI、维度人数及比例一致。
9. 至少包含一个低覆盖班级、一个高效度提示比例班级、一个小样本单元格及可由差分推算该值的上级汇总；断言 UI/API/导出均不能泄露。
10. 班级统计事实摘要只读取后端可发布数值，人工研判草稿在无正式记录服务时不声称已保存。

建议 Mock 文件：`analytics-scale-config.mock.json`、`analytics-school.mock.json`、`analytics-results.mock.json`、`analytics-permissions.mock.json`，并配套 `analytics-mock-invariants.test`。**上述文件名为待生成建议，不代表当前交付包含这些 JSON 文件。**

| UAT-22 | 纳入模式切换 | 全部已计算/效度未提示切换后 KPI、图表、表格、层级比较及导出基于相同模式与快照；默认模式未经确认不进入正式报表 |
| UAT-23 | 样本质量说明 | 全校、年级、班级展示应测、技术完成、有效可评价、效度提示与覆盖率分子分母；无批准门槛不生成“已达标/不可信”判断 |
| UAT-24 | 原始分比较边界 | 不同满分维度的均分不能被自动转换为“严重程度”或临床排行；维度高分与正式筛查信号分别命名 |
| UAT-25 | 心理测量术语 | 八维度采用正式配置及已审定的解释词库，不将“过敏倾向”解释为医学过敏，不输出诊断/患病率 |
| UAT-26 | 重点题安全下钻 | 聚合只显示工作量；重点题原始回答通过专门授权、理由与响应前审计查看，领导角色不允许调用 |
| UAT-27 | 班级专业研判 | 统计事实只读且可追溯，心理老师可人工确认主题；未实现正式保存时不显示成功状态或假记录 |
| UAT-28 | 低覆盖班级 | 同比例但不同完成量的班级分别显示实际 N 和覆盖率，并提示仅代表已纳入样本；不自动推导原因 |
| UAT-29 | 组合筛选差分保护 | 切换时间/维度/班级/效度模式、查看上下级与导出均不能恢复被抑制个人单元格 |
| UAT-30 | 多维度共同高分（P1） | 学生按稳定 ID 去重，组合数据不等于疾病诊断，领导端不可通过组合查询识别个人 |
| UAT-31 | 历史变化解释（P1） | 输出实际分、区间及样本变化；没有正式可靠变化模型时不生成“改善/恶化/活动有效” |
| UAT-32 | 匿名教育需求（P1） | 不回写量表评分，不以未高分拒绝普及性活动，匿名小样本仍限制披露 |
