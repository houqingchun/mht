# MHT 测评记录导入 · 文件格式规范

本文是「数据中心 → MHT测评记录导入」这条链路上，**一份文件能被接受的全部条件**。

它对着 `backend/app/services/assessment_import_service.py` 的现值写（V2.2.0 / 含 §5.26、§5.27
两次表头判据放宽），不是对着界面上的提示小字写——**两处不一致的地方在第三节末尾单独列出**，
那些地方以本文为准。

- 面向学校的那一份（去掉实现细节、只讲怎么填）见第六节，可直接转发。
- 维护者要改判据时：本文里每一条判据都能在 `parse_assessment_import`（列级）与
  `_row_from_cells` → `_parse_*`（行级）里找到对应的一行。

---

## 一、文件层（不满足就整份退回，一行都不读）

| 项目 | 要求 | 不满足时的提示 |
|---|---|---|
| 扩展名 | **必须是 `.csv`** | `只支持 .csv 文件，请先将文件另存为 .csv 后重试` |
| 编码 | **UTF-8**（带不带 BOM 都认）或 **GBK** 都认；UTF-16 只在**带 BOM** 时认 | `文件不是 UTF-8 或 GBK 编码的文本，请另存为 CSV 后重试` |
| 表头位置 | **必须在第 1 行**，前面不能有标题行、说明行或空行 | 表现为「缺少列：姓名、性别…」那一整串 |
| 分隔符 | 逗号 | 同上 |
| 内容 | 至少一行数据 | `文件里没有数据` |

三点说明：

- **`.xlsx` 请先「另存为 CSV」。** 这条链路上没有 Excel 解析（`openpyxl` 是刻意不引入的），
  走的是外部平台导出 / WPS / Excel 的「另存为 CSV」。拿 `.xlsx` 直接喂进来会读成一行乱码，
  每一行都报「缺少姓名」——所以扩展名一律整份拒掉。
- **全空行会被自动丢掉**（Excel 常见的尾部空行不会变成一行错误）。
  但**中间的标题行不会被跳过**——那就是上面「表头必须在第 1 行」那条。
- **多余的列会被忽略，不报错。** 比如加一列「学号」：这份导入不需要学号（见第四节），
  那一列不会被认领，也不会影响解析。

## 二、表头列（列级校验）

### 2.1 必备 5 列 + 选填 1 列

| 列 | 必填 | 认得的写法（`FIELD_ALIASES`） |
|---|---|---|
| 姓名 | ✔ | `姓名`、`学生姓名`、`name` |
| 性别 | ✔ | `性别`、`gender` |
| 年龄 | ✔ | `年龄`、`age` |
| 年级 | ✔ | `年级`、`grade` |
| 班级 | ✔ | `班级`、`班级名称`、`class_name` |
| 所用时间 | ✘ | `所用时间`、`用时`、`作答用时`、`duration` |

缺哪个报哪个，一次报全：`缺少列：姓名、性别`。

**「列必须在」与「格子必须填」是两件事**：年龄列必须在表头里，但某一行的年龄格子空着不算错
（只是匹配时少一个消歧依据）。姓名、性别那两格空着才是错（见第三节）。

英文别名按**不区分大小写**认（`Name` / `NAME` 都行），中文别名逐字比。

### 2.2 两种形态，至少满足一种

#### 形态 A —— 完整答案（100 个题号列）

100 道题**一个不少、一个不重**。少了报：`缺少题号列：3、7`；重了报：`重复的题号列：1`。

题号列认得的写法：

| 写法 | 说明 |
|---|---|
| `1.题干` | 最标准，模板就是这种 |
| `1 题干` | 数字后跟空白 |
| `第1题`、`第1题你晚上要睡觉时` | 带「第…题」标记的，**后面接什么都可以** |
| `Q1`、`Q1你晚上` | 带 `Q`/`q` 标记的，**后面接什么都可以** |

而**只写数字的**（没有 `第` / `Q` 标记）必须跟一个分隔符、空白或直接行尾——
`1.` `1、` `1．` `1)` `1。` `1:` `1：` `1）` `1 ` 都行。

这条区分是有意的：它让 `1班人数`、`1组` 这类列名**不会被误当成第 1 题**。
若统一放宽成「数字后面只要不是数字就算」，那一列会被吃成第 1 题、与真正的第 1 题撞车，
一份本来完好的文件拿到的是「重复的题号列：1」——**把「拒绝」换成了「误收」，而误收更糟**
（它不报错）。见 CLAUDE.md §5.27。

题号只认 1–100；写了 `101.题干` 那一列会被直接忽略（不是错误）。

#### 形态 B —— 只有汇总分

至少要有一列总分：

| 认得的写法 | 不认的 |
|---|---|
| `总分`、`总得分`、`总分（标准分）`、`总得分（标准分）` | **`总分（原始分）`** |

判据是**归一化之后的形状**（`_normalize_header_label`：NFKC + 去掉空白与括号字符本身）：

- 括号的**全角半角、中间有几个空格都不影响**——`总分(标准分)`、`总分 （ 标准分 ）` 都认；
- 但**括号里的字要一致**——`总分（原始分）` 归一化后是 `总分原始分`，不在这一档里，会被拒。

另可选 8 个维度列，名字逐字是
`学习焦虑`、`对人焦虑`、`孤独倾向`、`自责倾向`、`过敏倾向`、`身体症状`、`恐怖倾向`、`冲动倾向`。

#### 两种都在时报哪种？

**按 A 走。** 本地有原始答案，就没有理由去信平台算的分；这也让一份两边都带的文件
不会因为多了一列而变成另一条路。

#### 两种都没有

整份退回，提示是：

> 表头里既没有认出任何题号列（题号列应写成 1.题干，1 题干、第1题、Q1 这类写法也认），
> 也没有「总分」列（总分（标准分）这类写法也认，括号与空格不影响）。
> 包含 100 道原始答案的文件与只包含汇总分数的文件都能导入，但至少要认得出其中一种

## 三、逐格取值（行级校验）

这一节要分清**「拦」与「只提示不拦」**——后者那一行照常导入，只是在导入明细里带一句话。

| 列 | 认什么 | 不认会怎样 |
|---|---|---|
| 姓名 | 非空 | **拦**：`缺少姓名` |
| 性别 | `2` / `男` → 男；`1` / `女` → 女 | 空 → **拦**：`缺少性别`；其他 → **拦**：`性别 2 表示男、1 表示女` |
| 年龄 | 1–99 的整数 | 空 → 不报；读不出 → **只提示**：`年龄「X」无法识别，已忽略` |
| 年级 | `1`/`2`/`3`；也认 `7`/`8`/`9`；也认 `初一`/`初二`/`初三` | 空 → **拦**：`缺少年级`；其他 → **拦**：`年级应为 1/2/3（或 初一/初二/初三）` |
| 班级 | `4`（= 初一 4 班，内部补成 `704`）；也认三位编号 `704` | 非数字或超过三位 → **拦**：`班级格式应为 4（初一 4 班）` |
| 所用时间 | 纯数字，或 `3600秒` / `3600s`（`S` 也认） | 空 → 不报；读不出 → **只提示**：`作答用时「X」无法识别，已留空` |
| 答案（形态 A） | `1`/`是`/`YES` → 是；`0`/`否`/`NO` → 否 | 空 → **拦**：`第 N 题未作答`；其他 → **拦**：`第 N 题「X」的答案应为 1（是）或 0（否）` |
| 总分（形态 B） | **0–90** 的整数 | 空 → **拦**：`缺少总分`；非整数 → **拦**：`总分「X」不是 0–90 的整数`；越界 → **拦**：`总分 N 超出 0–90 的范围` |
| 维度分（形态 B） | 0–100 的整数 | 空 → 跳过；读不出 → **只提示**：`维度「X」的分数「Y」无法识别，已留空` |

**一句话记法：能决定这一行进不进得去的（姓名 / 性别 / 年级 / 班级 / 答案 / 总分）是「拦」；
只用来消歧或补格的（年龄 / 用时 / 维度分）只「提示」。**

这条分界不是随手划的：总分是汇总文件里**唯一的**分数来源，没有它导进去的是一场没有任何结果的
空会话——在界面上与「这个学生测了但是没事」长得一模一样，所以宁可让操作员改文件；
而年龄只用来消歧，读不出来这一行照样进得去，只是弱了一点。

### 3.1 两处「界面提示与判据不完全一致」，以判据为准

| 界面小字写的是 | 实际还认 |
|---|---|
| `年级应为 1/2/3（或 初一/初二/初三）` | **还认 `7`/`8`/`9`**（7→初一、8→初二、9→初三） |
| `班级格式应为 4（初一 4 班）` | **还认三位编号 `704`**，但**首位必须与年级一致** |

三位编号的规则：首位 `7`→初一、`8`→初二、`9`→初三；对不上时报
`班级 704 属于初一，与年级 初二 不一致`。**这是这一层唯一「填错了却看着像对的」情况**——
两列各自看都合法，合起来矛盾。所以年级列与班级列必须同时填对。

## 四、这一行会落到谁头上（匹配）

匹配用的是 **姓名 + 年级 + 班级**（这份导入**不看学号**）：

1. 先按年级 + 班级找到那个班，再按姓名找这个人；
2. 班上同名时，用**性别 + 年龄**消歧，并在明细里提示
   `同班有 N 名同名同学，已按性别与年龄定位到 Sxxx`；
3. 班里没有这个班 → 报「班级不存在」；班里有这个班但没有这个人 → 报「学生不存在」。
   **两种原因分开报**，不会给出会误导人的诊断；
4. 同名同班、性别年龄也分不出来 → 这一行标记为「无法确定」，**不会自动导入**，要人工指定。

两条与范围有关的行为：

- **超出数据范围与「没有这个学生」返回逐字相同的一句话。** 否则一个只带本班范围的心理老师
  可以用上传文件来枚举全校名册（发一个名字，看回的是「不在你的范围内」还是「没这个人」）。
- **范围过滤发生在数候选人数之前**——「这个人在这里等于不存在」，不是「找到了但不让导入」。

所以**年级列与班级列必须与名册一致**，这是这份文件最容易出问题的地方。

## 五、批次字段（在界面上填，不属于文件）

| 字段 | 规则 | 不满足时 |
|---|---|---|
| 批次名称 | 必填，**最多 128 字** | `批次名称不能为空` / `批次名称过长（最多 128 字）` |
| 测评日期 | 必填，**不能晚于今天** | `测评日期不能晚于今天` |

同一位操作员、同一个文件、仍处于预览状态、且绑定同一场任务时，系统会**复用同一个批次**
而不是再建一个——所以刷新页面重新上传不会留下一串重复记录。

## 六、给学校的那一份（可直接转发）

### 6.1 最省事的做法

**点界面上的「下载模板」，照它填。** 模板逐字长这样：

- 表头：`姓名,性别,年龄,年级,班级,所用时间,1.题干,2.题干,…,100.题干`
- 样例行：`示例学生,1,12,1,4,3600秒,0,0,…,0`（100 个 `0`）
- 编码：UTF-8 带 BOM

把样例那一行删掉、换成自己的数据就行。

### 6.2 三个最容易踩的坑

1. **性别是 `2` 表示男、`1` 表示女**（与很多平台的约定相反）。
2. **总分上限是 90**，不是 100——效度题不计入总分。
3. **班级写 `4` 或写 `704` 都行，但写三位时首位必须与年级对得上**：
   `704` 配「初一」对，配「初二」就报错。

### 6.3 如果装的是旧版本

本文第二节里那几条「放宽」是最近才进的：

| 放宽项 | 从哪一版起 |
|---|---|
| 题号列认 `1 题干` / `第1题` / `Q1`（含题号紧贴题干，如 `第1题你晚上要睡觉时`） | V2.2.0 |
| 总分列认 `总分（标准分）`、全角半角括号与空格 | V2.2.0 |

在**旧版本**（V1.1.6 及更早）上，题号列请一律写成 `1.题干` 这种（数字 + 点 + 题干），
总分列写 `总分` 或 `总分（标准分）`——其余写法可能被拒。

> 顺带记一条已知的措辞与实现对不上：V1.1.6 及更早版本的报错文案里**承诺**认 `第1题`、`Q1`，
> 而当时的正则并不认（两支共用了同一段尾部判据）。V2.2.0 把两支拆开之后才一致。
> 所以旧版本上「报错文案说要认、实际不认」这件事是真实存在的。

## 七、维护者备注

- 判据全部集中在两处：`parse_assessment_import`（列级：扩展名、表头、题号完整性）
  与 `_row_from_cells` → `_parse_grade` / `_parse_class` / `_parse_age` / `_parse_duration` /
  `_parse_answers` / `_parse_total_score` / `_parse_dimension_scores`（行级：逐格取值）。
- `_columns_from_header` 的**级联次序本身就是判据**：
  `FIELD_ALIASES` → 归一化后比 `SUMMARY_TOTAL_LABELS_NORMALIZED` → `DIMENSION_BY_LABEL` →
  `_QUESTION_HEADER`（**最后**）。题号识别排最后，是放宽正则的安全前提。
- 「100 题一个不少」那道检查是放宽题号判据的**兜底防线**：即使哪天正则放得过宽，
  一份列数不对的文件仍然会被这条挡住。
- 改本文里任何一条判据时，对应的中文提示语也在同一处函数里，**两处要一起改**；
  另外第三节 3.1 那张「界面提示与判据不一致」的表，是界面小字与后端判据的**同步点**。
