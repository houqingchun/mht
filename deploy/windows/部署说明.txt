----------------------------------------------------------------
 动手之前：这台电脑上要装好 Python 3.11（64 位）
----------------------------------------------------------------

**这是必须的，没装就装不上这套系统。** 先花两分钟确认一下。

为什么：这套程序本身是用 Python 写的，需要一个 Python 才能跑起来。
（以前它可以自带一个，现在不带了——包小了 21MB，代价就是要用这台
电脑上已经有的那一个。）

必须是 **3.11** 这个版本，而且必须是 **64 位**，别的都不行。
程序依赖的一批组件是按 3.11 编译的，换版本装不上。

怎么装：

   1. 打开浏览器，访问 https://www.python.org/downloads/
   2. 找到 Python 3.11 那一栏（页面上写着 "Looking for Python 3.11?"），
      点它，下载 **Windows installer (64-bit)**。
   3. 双击下载下来的那个文件（名字像 python-3.11.x-amd64.exe）。
   4. ★ **安装界面的第一页，最下面有一个勾选框，写着
        "Add python.exe to PATH"（把 Python 加到 PATH），把它勾上。**
      这一步忘了勾，安装程序很可能找不到 Python。
   5. 点 "Install Now"，等它装完，点 Close。

怎么确认装好了：按 Win+R，输入 cmd 回车，在黑色的窗口里输入

    python --version

回车。屏幕上应该出现 `Python 3.11.x`。出现了就对了。

   ⚠ 如果它打开了一个「应用商店」窗口，说明这台电脑上只有微软商店
     那个占位的假 Python，真正的还没装。关掉商店窗口，照上面装一遍。
   ⚠ 如果显示的版本不是 3.11（比如 3.12、3.10），那也不行：
     请照上面把 3.11 装上，安装程序会自己挑对的那一个。

   装完之后**不要去卸载或者升级它**。这套系统开机要用的就是它，
   它没了服务就起不来（那时候「查看状态.bat」会明确告诉你）。
   以后要升 Python，先在这套系统上升级重装一遍。


----------------------------------------------------------------
 先看这一节：你要的是哪一种？
----------------------------------------------------------------

装的时候会先问你一个问题，答案决定了后面所有事情。**选错了要卸载
重装**（装完改不了），所以先想清楚再动手。

拿不准就问自己一句：

    除了我之外，还有别人要用浏览器打开这个系统吗？

  没有 → 选 1（单机）
  有   → 选 2（局域网）

  1. 单机 —— 只有这台电脑用
     装在你自己的账号下，**不需要管理员权限**；不注册开机自启，
     也不放行防火墙。要用的时候双击「启动服务.bat」，电脑一关
     服务就停了。别的电脑连不过来。

  2. 局域网 —— 同一校园网里的老师们都要连过来
     当服务器用：装到 C:\xinliceping，装的时候要管理员权限，
     装完在后台一直跑，这台机器重启之后也不用谁去点。

下面是手把手的步骤，凡是两种不一样的地方都分开写了。
如果你只需要单机，看到「局域网」那几段可以直接跳过去。


----------------------------------------------------------------
 第一步：把压缩包解压出来
----------------------------------------------------------------

右键那个 zip 文件 →「全部解压缩」。

解压到哪都行（桌面、D 盘、U 盘都可以）。建议就解压到桌面。

    ⚠ 注意：要在解压出来的**文件夹里面**操作，不要直接在
      zip 压缩包里双击里面的文件——那样装不上。

解压好之后，你会看到一个文件夹，里面有这些：

      一键安装.bat        ← 第二步要双击的就是它
      backend\
      frontend\
      wheels\
      data\
      deploy\
      部署说明.txt        ← 你正在看的这一份


----------------------------------------------------------------
 第二步：双击「一键安装.bat」
----------------------------------------------------------------

双击它。会出现一个黑色的窗口。

    局域网：接着会弹出一个「你要允许此应用对你的设备进行更改吗？」
            ——点「是」。（那个黑窗口别关掉，它在等。）
    单机：  **不会弹**这个。如果弹了，说明刚才第一个问题选错了。

接下来它会问你几个问题：

    0. 这套系统怎么用？
         （就是「先看这一节」里说的那两种，装过一次的不会再问）

       输入 1 或 2，直接回车 = 1（单机）。

       ⚠ 已经装过的那台机器上**不问这一问**，直接沿用上次的用法。
         屏幕上会写一行「沿用上次的用法：……」，看到它就别找这一问了。

    1. 安装到哪个目录
       单机：直接回车 = 你的用户目录下（屏幕上会显示完整路径）
       局域网：直接回车 = C:\xinliceping

    2. Web 服务端口
       直接回车 = 8000

    3. MySQL 连接信息（4 个问题 + 密码）
       数据库地址     直接回车 = 127.0.0.1
       数据库端口     直接回车 = 3306
       数据库用户名   直接回车 = root
       数据库密码     输入时不显示，输完回车
       数据库名       直接回车 = xinliceping

       ⚠ 这里的密码要填**这台机器上 MySQL 的 root 密码**，
         就是当初装 MySQL 时设的那个。填错了装不下去，
         会明确告诉你「连不上数据库」。

    4. 这次数据库由谁准备？
       输入 1、2 或 3，直接回车 = 1。

         1 = 全由「一键安装」来准备：它会建库、建表、把基础数据
             （量表和管理员账号）写进去，并把管理员密码设成你
             下面输入的那一个。**绝大多数情况选这个。**

         2 = 库和表都由我自己准备好：它不建库、不建表、不写基础
             数据、也不动管理员密码，只把「连哪个库」写进配置。
             选了 2 请一定看后面「数据库我自己准备」那一节。

         3 = 库和表都由我自己准备好，**基础数据和管理员密码交给
             安装程序**：它不建库、不建表，只校对一次表结构、
             写入基础数据（量表、admin 账号）、并设管理员密码。
             选了 3 请一定看后面「数据库和表我自己建好了」那一节。

       三者只差一件事：**这个库里，哪几样归你**。
       拿不准就选 1——选 2 与选 3 是给「我自己先把数据库那边弄好」
       的人用的，选错了会有一大段东西要你手工补。

       ⚠ 装过一次的机器上这一问**照样会问**（用法那一问不会）。
         上一次选的是哪个，照上一次的选就行。

    5. 管理员密码（输两遍）
       这是给你自己登录用的，用户名固定是 admin。
       至少 6 位。请记在一个安全的地方。

       （输错了不要紧：装完之后双击「重置管理员密码.bat」可以随时改。）
       （上一问答了 2 的话，**不会**出现这一问——admin 那个账号
         属于你准备的那个库，安装程序不去碰它。答了 1 或 3 才会有。）

然后它就开始装了。屏幕上会一行一行往下滚，最后出现：

     ======================================================
       安装完成
     ======================================================
       在浏览器里打开：
          http://127.0.0.1:8000/            ← 单机
          http://10.0.0.5:8000/             ← 局域网
     ======================================================

看到这一段就是装好了。按回车关闭窗口。


----------------------------------------------------------------
 第三步：让人能打开它
----------------------------------------------------------------

  ● 单机：做到这里就完了。在**这台电脑**上打开浏览器，
    访问 http://127.0.0.1:8000/ 就能用。没有别的电脑要管。

  ● 局域网：上面那一行 http://10.0.0.5:8000/ 就是老师要在浏览器里
    打开的地址，把它发给老师们。

        ⚠ 那个 IP 地址**每台机器不一样**，请照你屏幕上显示的那一串
          抄，不要照抄这份说明书里的例子。

    在**这台服务器**上访问 http://127.0.0.1:8000/ 也可以
    （127.0.0.1 是「本机」的意思，只在这台电脑上打得开）。


================================================================
 数据库我自己准备
 （装的时候第 4 问选了 2 才需要看这一节；选 1 与选 3 的可以跳过去）
================================================================

选 2 的意思是：**库归你，程序归安装程序。** 那种情况下安装程序不会
给你建库、不会往库里写基础数据（量表、admin 账号），也不会设管理员
密码。它只做它该做的两件事：

   · 把「连哪个库」写进配置文件（不写的话程序连不上）；
   · 把表结构升到这一版（这件事是程序自己的事，不删你的数据）。

所以**库、表、基础数据这三样要你自己补齐**。分两段时间做：

  ① 装之前：先把**库**建出来。
     用 MySQL 的工具（MySQL Workbench，或者命令行）建一个库，
     名字要和你装的时候填的「数据库名」一字不差（默认 xinliceping），
     字符集选 utf8mb4。

     库不存在的话，安装会在「第 4 步 / 共 6 步：准备数据库」停下来，
     并明确告诉你连不上、要你先建库——那一句就是这一步没做的意思。

  ② 装之后：把**基础数据**灌进去（表结构安装时已经建好了）。
     在安装目录下找到 backend 子目录，在里面开一个命令行窗口
     （地址栏里输入 cmd 回车也行），跑这三条，顺序不要换：

         cd /d C:\xinliceping\backend
         ..\runtime\venv\Scripts\python.exe -m app.db.create_database
         ..\runtime\venv\Scripts\python.exe -m alembic upgrade head
         ..\runtime\venv\Scripts\python.exe -m app.db.seed

       第一条「库已经在了就什么都不做」，第二条安装时已经跑过一次
       （重跑是安全的），真正干活的是第三条。

       它写进去的东西：MHT 量表与评分规则、admin 管理员账号、
       一个基线测评任务。**admin 的密码是内置的初始密码 123456**，
       登录进去之后请立刻双击「重置管理员密码.bat」改成你自己的。

       装完之后这三条都做完了，再双击一次「启动服务.bat」
       （单机用法；局域网用法直接双击「重启服务.bat」，或者等它自己
       重试——服务会自己发现库通了）。

  ⚠ 单机用法的安装目录在 C:\Users\你的用户名\AppData\Local\xinliceping
     （收尾那几行打印过完整路径），上面 `cd /d` 那一行换成你自己的。
  ⚠ 这三条命令要在安装**之后**跑：那个 python.exe 是安装时才建出来的。


================================================================
 数据库和表我自己建好了
 （装的时候第 4 问选了 3 才需要看这一节）
================================================================

选 3 的意思是：**库和表归你，数据归安装程序。** 这是给「我已经用
自己的工具把库和表建好了，剩下的一键完成」这种情形用的。

跟选 2 比，只有一件事不一样：**基础数据和管理员密码由安装程序来写**，
你不用装完再去跑那三条命令。装完直接登录就行，密码就是你第 5 问输入的
那一个（不是选 2 那种「内置的 123456」）。

安装程序在这一步会做一件事，你要知道：

   · 它**只看不改**：把你库里的表名、列名和它要的比一遍。对得上，
     就往 `alembic_version` 这张表里写一行版本号——那是 Alembic
     （程序用来管理表结构的工具）自己的**版本记录表**，不是你数据的一部分；
     它据此知道「这个库的表已经是这一版了」，以后升级只需要补差异。
     你的业务表一行都不动。

   · 对不上，它会**停下来**，并把缺哪张表、缺哪一列**逐条列出来**。
     这种情况说明你那份建表语句不是这一版的。参照下面「怎么拿到正确的
     建表语句」，别再反复重跑。

   · 如果 `alembic_version` 这张表已经存在，但里面是空的、或者写着
     一个它不认识的版本号，它同样会停下来，并告诉你把那张表 DROP 掉
     再重跑一次（只动那一本账，业务表不碰）。多半是这份库的结构是从
     别处整份导过来的——`mysqldump --no-data` 会把这张表一起导出来，
     而它是空的。

怎么拿到正确的建表语句（**包里就带着这一份**）：

     **部署包里 `backend\sql\schema_mysql8.sql` 就是这一版的建表语句。**
     它已经按外键次序排好（父表在前），直接用你建表时用的那个工具整份
     执行一遍即可——不需要先装一次程序，也不需要网络。文件开头写着用法
     和两条注意事项，看一眼再执行。

     它开头还有一句话要照做：**建完表之后，安装程序会自己跑一次升级**
     （那是它的第 4 步），你不用自己去跑。所以顺序是「先把表建出来，
     再开始安装」，不是反过来。

     如果你更习惯从一台已经装好的库里导出，也可以在另一台机器上按
     「选 1」装一次，然后用你建表时用的那个工具（MySQL Workbench /
     Navicat / phpMyAdmin / mysqldump 都行）把那个库的**表结构**导出来
     （只要结构、不要数据），再导进这个库。

     用 mysqldump 的话是这样（注意那两个开关，它们是有意的）：

         mysqldump --no-data --skip-add-drop-table ^
             --ignore-table=xinliceping.alembic_version xinliceping > schema.sql

     第一个开关让导出的内容里没有 DROP TABLE（导进一个已经有表的库时
     不会把表先删掉）；第二个把 `alembic_version` 这张表排除掉——
     **别把这张表一起导进来**，一份空的就够让安装程序以为这个库的表
     已经归它管，从此不再校对。它就是上面说的那本账；让安装程序自己
     去写这一行。

     （命令行窗口里换行要打 ^，一行写完也行。库名换成你自己的。）

  ⚠ 安装程序**不建库也不建表**，所以它会先确认连得上：库名写错、库还没
     建出来，都会在「第 4 步 / 共 6 步」停下来，并明确告诉你原因。
  ⚠ 表结构这一件事**升级时也一样会校对**，所以你不用记「哪次才跑」。


================================================================
 装完之后，请做这三件事
================================================================

1. 用 admin 和你刚才设的密码登录。
   系统会要求你先改一次密码——这是正常的，照做就行。

   （装的时候第 4 问答了 2 的：这一条要看你自己的库——admin 的密码是你准备
     数据库时那一个；如果基础数据还没灌，先按上面「数据库我自己准备」那一节
     把三条命令跑完，再回来登录。答了 1 或 3 的用的是你刚才输入的那一个。）

2. 到「账号与权限 → 新建账号」里，建心理老师和德育领导的账号
   （员工用手机号登录）。

3. 到「组织学生 → 学生信息导入」里，把学生名册导进来。

   做完这三件，系统就能用了。

   **刚装完时，「重点学生」「测评任务」这些页面是空的，这是正常的。**
   admin 是管账号和配置的账号，按设计看不到学生的心理数据——那部分要等
   心理老师的账号建好、名册导进来之后才会有内容。别把「空」当成装坏了。


================================================================
 平时怎么用
================================================================

  ● 单机：

    **要用的时候双击「启动服务.bat」。**

    ★ 双击之后屏幕上会多出一个**黑色的窗口**——那个窗口**就是服务
      本身**，它在跑，网页才打得开。用完了**把这个窗口关掉**，服务
      就停了（这就是「用完就关」的意思）。

        别的窗口都可以关，只有这个别关——关掉它网页就打不开了。

    关掉之后要再用，再双击一次「启动服务.bat」，它会再开一个同样的
    窗口。**注销或者重启这台电脑，服务也会停**（那正是我们要的）。

    这个按钮在你的用户目录下（安装时收尾那几行打印过完整路径，
    再找不着就看看「查看状态.bat」的第一行）。嫌麻烦的话，
    右键它 →「发送到」→「桌面快捷方式」，以后从桌面点。

  ● 局域网：

    **平时什么都不用做。** 服务器开着，服务就在跑；这台电脑重启之后，
    服务也会自己起来，不需要有人登录，不需要谁去点什么东西。
    这一种用法下服务**没有窗口**（它就该在后台待着）。

安装目录里有这几个按钮，需要的时候双击：

  启动服务.bat          服务停了的时候用它拉起来
  停止服务.bat          要维护的时候先停掉
  重启服务.bat          改了配置之后用它
  查看状态.bat          ★ 最常用：看服务在不在、老师该访问哪个地址
  查看日志.bat          出问题的时候看这个（会打开日志文件夹）
  备份数据.bat          ★ 请定期跑，见下面
  重置管理员密码.bat    admin 密码忘了的时候用
  卸载.bat              不用这套系统了的时候用

  ⚠ 忘了 admin 密码怎么办？
     双击「重置管理员密码.bat」，按提示输两遍新密码就行，**不用重新装**。
     （如果密码输错太多次把账号锁住了，也不用等——重设密码会一并解锁。）

  ⚠ 再双击一次「一键安装.bat」是**升级**，不是重装：
     * 它不会问你密码，也**不会**把你改过的密码冲掉；
     * 它也不会问你数据库连接，更不会动数据库里的数据；
     * **但它会问一次第 4 问「这次数据库由谁准备」**（用法那一问才是
       真的不问）。照上次的答案选就行；拿不准就选 1——升级时它只是
       顺手确认那个库还在（不在的话会建一个空的）。三种都不会重建库、
       不会重跑基线清理、不会碰你已经录进去的数据。
     * 它只更新程序文件、校对一次表结构、跑一次数据库迁移。
       （校对表结构那一步三种选择都会跑：它只读你的表名与列名，
       对得上就什么都不做。它不删数据。）
     * **原来的服务不用你先去停。** 安装程序自己会先把服务停掉，
       再开始换程序文件——你不用先双击「停止服务.bat」。
       （升级那几分钟里网页打不开，是正常的；装完它自己会重新起来。）
     所以想升级就直接双击，不用担心把已经配好、已经录进去的东西弄丢。

     只想单独把**数据库**升上去、或者想拿一份 .sql 自己执行的话，
     看下面「从 V1.0.0 升到这一版」那一节。

这些按钮要「以管理员身份运行」的几个会自己弹授权窗口，点「是」即可。
（单机用法一个都不需要。）

  ⚠ 想从「单机」换成「局域网」（或者反过来）**不能直接改**：
    先双击「卸载.bat」，再重新双击「一键安装.bat」并把第 0 问
    选成另一个。卸载不会动数据库里的东西。


================================================================
 从 V1.0.0 升到这一版
================================================================

升级要换两样东西：**程序文件**和**数据库**。正常情况下你只需要做一件事：

  ● 正常升级（绝大多数情况就是这一条）：
    把新版的压缩包解压、覆盖到安装目录，再**双击一次「一键安装.bat」**。
    程序文件和数据库它都会一起换掉。上面「平时怎么用」那一节的 ⚠ 里
    已经说过这件事（不用先停服务、不会动你的数据）。

下面这两种情况才需要往下看。

----------------------------------------------------------------
 情况一：想单独把数据库升上去
----------------------------------------------------------------

  双击   deploy\数据库增量升级.bat

  · 它**只动数据库**：不起服务，也不碰程序文件。
  · 什么时候用得上：想先把库升上去、过一会儿再开服务；或者后端起不来，
    想单独确认「库到底升上去了没有」。
  · 做的事与一键安装第 4 步**逐字相同**：先校对一次表结构，再执行迁移，
    最后**再校对一次**，并把最终的版本号念给你看。屏幕上最后那几行
    `alembic_version = …` 就是它自己报的，那是权威。
  · ⚠ 它要在**装过的**安装目录里双击（那个目录里才有运行环境和配置文件）。
    在新解压开的包里点它，它会明确告诉你还没有装过。

----------------------------------------------------------------
 情况二：应用服务器上装不了，只能拿一份 .sql 去执行
----------------------------------------------------------------

  那份文件在   backend\sql\upgrade_from_v1_0_0.sql

  它是从 V1.0.0 升到这一版的全量增量，交给数据库管理员执行就行：
  用 mysql 命令行、或者 MySQL Workbench 都可以。

  ⚠ **怎么执行写在那个文件自己的头里，这里不重述**——先备份、
    用哪个字符集、看到 `ERROR 1644` 是什么意思、怎么核对结果，
    那一段写得比这里全。两处各写一遍，过一阵就会有一处是旧的。

  ⚠ **它只该对 V1.0.0 的库执行一次。** 已经在跑这一版的库不要再跑
    （会撞「列已存在」，那是正常的，不是文件坏了）。
  ⚠ **执行之前先备份**（双击「备份数据.bat」，或者让数据库管理员
    用 mysqldump 导一份）。这一步没有替代品。

----------------------------------------------------------------
 两种办法做的是同一件事
----------------------------------------------------------------

  上面两条路跑的是**同一批数据库迁移**，所以**选一种就行，不要两种都跑**。
  拿不准用哪一种就选情况一（双击那个按钮）：它自己会检查、会报错、
  会告诉你在哪一步停下的。


----------------------------------------------------------------
 关于备份（这件事请认真对待）
----------------------------------------------------------------

双击「备份数据.bat」，它会导出一份当天数据的文件，放在安装目录下的
backups\ 文件夹里（屏幕上会打印出完整路径）。

**这份文件就在这台机器上。万一硬盘坏了，它救不了你。**

所以请定期（比如每月一次）把那个文件夹里的 .sql 文件拷到别的地方：
U 盘、另一台电脑、网盘，都行。

（备份脚本会自动删掉 30 天以前的旧文件，所以不用担心它越堆越大。
 反过来说，**超过 30 天没备份，就真的什么都没有了**。）

装了之后一个页面都打不开，而装的时候第 4 问选的是 2：先看上面
「数据库我自己准备」那一节。最常见的两个原因是**库还没建出来**、
或者**基础数据还没灌进去**（量表和 admin 账号都在那里面）。

装的时候第 4 问选的是 3、而它停在第 4 步说表结构对不上：看上面
「数据库和表我自己建好了」那一节——它会把缺哪张表、缺哪一列列出来，
按那一节的办法拿到正确的建表语句，别再反复重跑。

装的时候一步都走不完、停在一段英文错误上，或者装完之后服务怎么都起不来：
包里还有两个「手工启动」按钮，见下面「一键安装装不完的时候」那一节——
那两个按钮能把没做完的几步补上，并且当场把服务跑起来。

实在搞不定的时候：把「查看日志.bat」打开的那个文件夹里
最新的 server.log 发给做这套系统的技术人员。
装的时候失败的，把安装那一步屏幕上打印的日志文件发过去
（收尾那几行里有它的完整路径，一般在临时文件夹里）。


----------------------------------------------------------------
 如果装的时候被杀毒软件拦住了
----------------------------------------------------------------

装的时候会用到这台电脑上的 Python（就是开头那一节让你装的那个），
安装过程还会建出一批程序文件。杀毒软件**有可能**把其中某些动作当成
可疑行为，尤其是装到一半、正要在安装目录里生成运行环境的那几十秒。

被拦下来的表现是：装到一半停住，提示里出现「python.exe」或者
「无法加载 / 找不到」之类的话。

（顺带一提：这套程序自己不再附带 Python 了，所以「包里的 python.exe
被杀毒软件盯上」那种情况已经没有了。现在的风险在**安装过程**，
不在包里带了什么。）

遇到这种情况：

   1. 打开杀毒软件（或「Windows 安全中心」）→「保护历史记录」
      /「威胁历史记录」，看有没有拦截记录；
   2. 如果有，选择「允许」/「还原」，把安装目录加进排除项；
   3. 然后重新双击一次「一键安装.bat」。做过的步骤会重来一遍，
      但那是安全的，不会弄坏已经装好的部分。

   ⚠ 如果还是被拦下来，就改用下面「一键安装装不完的时候」那一节里的
     两个「手工启动」按钮——它们会把没做完的那几步接着做完。

**这套系统不往系统目录里写东西，也不改注册表。** 局域网用法会加一条
开机自启的计划和一条防火墙放行规则，卸载时都会清掉；单机用法这两样
都没有。所以放行它不会给这台电脑带来额外的风险。


----------------------------------------------------------------
 一键安装装不完的时候：包里还有两个「手工启动」按钮
----------------------------------------------------------------

如果「一键安装」在某一步停下、或者装完了网页却打不开，先别急着重装：
包里还有两个按钮，能把没做完的那几步补上，并让服务在这台电脑上跑起来。

它们在**你解压出来那个文件夹的 deploy 子文件夹里**（装完之后同一个位置也有）：

      deploy\手工启动后端.bat     ← 先试这一个
      deploy\手工启动前端.bat     ← 只有下面说的那一种情况才要用它

**多数情况只双击「手工启动后端.bat」就够了。** 没做完的几件事它会自己做
一遍（已经做过的不重做）：

   1. 检查这台电脑上的 Python 3.11（64 位）——就是本说明开头那一节让你
      装的那个——并用它建出运行环境。
   2. 看 backend\.env 这份配置在不在。不在就写一份出来，然后**停下来**、
      把内容打在屏幕上。你只要把里面的 CHANGE_ME 换成数据库口令，再双击
      一次这个按钮就行。
   3. 校对表结构、跑一次数据库迁移（只看表名列名，不删数据）。
   4. 库里如果什么都没有，写入基础数据（量表、评分规则、admin 账号）。

        写完之后它会告诉你：admin 的初始密码是 123456，首次登录会要求改，
        要现在就换成自己的，双击「重置管理员密码.bat」。

   5. **问你一句话**：要不要把这个库清成「只有管理员 + 量表与基本配置」。
      **真实学校用请输入 Y 再回车**（它会删掉种子里的演示名册）；直接
      回车 = 保留，什么都不动。
   6. 起服务。屏幕上出现「页面与接口：http://…」就是起来了。浏览器打开
      那个地址就是登录页（端口按配置文件里的来，默认 8000）。

     ⚠ 屏幕上那个黑窗口**就是服务本身**，跟「启动服务.bat」开出来的
       是同一回事：**窗口在，服务才在；关掉窗口，服务就停了。**

什么时候才需要**第二个**按钮：

     「手工启动前端.bat」只在你想让**前端单独占一个窗口**的时候用
     （比如你想把网页发到 5173 这个端口）。

     用法：先双击「手工启动后端.bat」并且**别关它**，再双击
     「手工启动前端.bat」。第二个窗口把页面发到 http://127.0.0.1:5173/，
     并把页面上所有接口请求转给第一个窗口。两个窗口都开着，系统才是
     完整的。

     ⚠ **不要用 `python -m http.server` 或者别的静态服务器去发这套前端。**
       那样登录页打得开，但**每一次登录都会失败**，页面提示「连不上后端
       服务」。这套前端的接口地址是相对路径，必须由「手工启动前端.bat」
       转发，别的发法都不行。

     ⚠ 两个窗口都关掉之后网页就打不开了；要再用，再双击一遍。

这两个按钮**不能替代安装**：它们用的是解压目录/安装目录里现成的那套东西
（运行环境、backend\.env、数据库），只是把安装没做完的几步补齐。想要
「装完就一直在后台跑、这台机器重启也不用管」（局域网那一种），仍然要
重跑一次「一键安装.bat」。

     ⚠ 它每一步做了什么、卡在哪，都会打在屏幕上；出错时最后那几行就是
       原因（最常见的一句是连不上数据库，多半是配置里的口令不对）。


----------------------------------------------------------------
 这套系统做不到的事（事先说清楚）
----------------------------------------------------------------

· 单机用法**只有这台电脑能打开**，同一间办公室的同事也连不过来——
  那是设计如此，不是坏了。要让老师们用，得按「局域网」重新装一次。

· 局域网用法只在**局域网**里用（同一个校园网内）。不要直接把它暴露到
  互联网上——那需要额外配 HTTPS，这里没有做。

· 只支持**一所学校**。多所学校共用一套系统需要另外开发。

· 备份不会自动上传，必须有人定期把备份文件拷走（见上面）。
